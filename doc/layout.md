# Layout

`SheenPage` is a full page with a large title that collapses into the toolbar (or no title, for a page whose content is its own heading); `SheenSectionLabel` and
`SheenSectionNote` frame groups; `SheenScrollEdge` and `SheenEdgeFade` soften edges; `SheenLayout` gives the
readable width and the wide-window breakpoints.
